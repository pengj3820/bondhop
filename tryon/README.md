# 固定模特 AI 换装 · 实验记录

## 实验 1：分层抠图（`pipeline/`）

流程：
1. `gen_model.py`：生成固定模特，标准姿势，画布 1024×1536。
2. `prep_model.py`：抠出人像，把脖子到脚踝的身体涂成绿幕，得到 `model_chroma.png`。
3. `gen_garment.py`：在绿幕模特上生成单件衣服。
   - 用 gpt-image-1.5、`input_fidelity=high`，不传蒙版。
   - 整体配准（`align.py`）+ 手臂 TPS 校正（`warp_fix.py`），再把编辑区域以外的像素强制贴回原图。
4. `extract.py`：抠出衣服图层。
   - 身体区域用色相比例判断绿幕，背景区域用 BiRefNet 抠图。
   - 覆盖检查：沿衣服边缘露出的窄条身体（宽度小于 21 像素）由衣服补齐；躯干覆盖率必须 ≥ 97%。
5. `build_manifest.py`：生成"塞进去"和"外套内搭"两种裁剪图，以及 `manifest.json`。
6. `compose.py`：按图层叠加，生成搭配预览。

结论：对普通的上衣、下装、连衣裙、外套可行，7 件全部通过质检。但**处理不了**以下元素：
- 薄纱、蕾丝、网袜等半透明材质
- 翅膀、尾巴等在身体后面的部件
- 头饰
- 手套、手持道具
- 整套造型

## 实验 2：整套造型直接生成（`pipeline/gen_look_experiment.py`）

把固定模特原图连同造型描述交给 gpt-image-1.5（高保真），直接生成整张图。

- 哥特洛丽塔造型成功：薄纱、丝袜、头饰都能处理。
- 人物整体有约 8% 的缩放和位移，需要做基于脸部的对齐。
- 暗黑天使造型被 OpenAI 安全审核连续拒绝，暴露程度较高的服装可能需要换生成服务。
