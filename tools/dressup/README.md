# 2D 换装素材流程（试验代码）

这里是 AI 生成写实换装素材的试验脚本：在固定素模上生成衣服、抠成透明图层、自动检查、导出给前端叠图换装。脚本是在探索过程中逐步写出来的，后续需要整理成正式工具。

## 已确定的需求

- 2D 换装，**人物不需要动**（不用 Spine / Live2D），支持少量**固定姿势**切换（每个姿势预生成图层，切换时整体换图）。
- 素模：**写实欧洲女性**，模特站姿，**踮脚**（像穿高跟鞋，一只脚略在前），双手自然下垂、手和大腿之间留空隙，头发盘成低丸子头露出耳朵。
- 姿势 A：上面的模特站姿（主换装姿势）。
- 姿势 B：单手打招呼（画面左侧手臂抬起，前臂竖直、掌心朝前），其余部位和 A 完全相同；下装和鞋复用 A 的图层，生成后把 B 素模的下半身替换为 A 的，保证对齐。
- 首批 10 件：白色圆领 T 恤、蓝白条纹长袖衬衫、米色针织毛衣、浅蓝牛仔夹克（敞开）、直筒牛仔裤、黑色百褶短裙、卡其阔腿裤、黄色碎花连衣裙、黑色细跟高跟鞋、黑色高跟短靴。
- 先用 **HTML 页面**看效果（不写 Unity 代码），必须**支持换肤色**，抠图必须**干净**。

## 流程

1. `gen.py`：调用 OpenAI 图像接口（`gpt-image-2` 生成/编辑；透明背景只有 `gpt-image-1.x` 支持）。云会话里认证由网络代理注入，脚本不保存 Key。
2. `make.py` / `dress.py` / `items.py`：在素模上“穿上”每件衣服（编辑素模图）。
3. `make_raise2.py`：在第二个姿势上生成同一件衣服，**必须同时传入第一个姿势的衣服图作为参考**，否则花纹会变。
4. `pipeline.py`：抠图层 + 皮肤通道 + 三种肤色合成 + 检查。关键做法：
   - 与素模逐像素比较找变化区域，结合人体分割（MediaPipe 多类分割）和颜色模型。
   - 衣服里露出的“新皮肤”单独存为皮肤通道，前端换肤色时一起改色；其余皮肤一律用素模自己的。
   - 边缘像素按颜色拆成“衣服 + 背后颜色”，只保留衣服部分（去掉细线描边）。
   - 图层里剔除打底衣颜色的像素（否则叠穿时会盖住下层衣服）。
5. `vis_drift.py`：只用衣服没遮住的关节衡量姿势漂移（被遮住的髋部估计不可靠）。
6. `combo.py`：多件叠穿检查。
7. `export.py` / `export_mask.py`：按统一画布导出裁剪后的 WebP 图层、皮肤蒙版、说明文件（manifest.json）。
8. `pages/build_dressup_page.py`：生成 HTML 换装预览（WebGL shader 用皮肤蒙版实时换肤色）。

`export_rig.py`、`export_raise.py`、`build_spine.py`、`build_anims.py`、`pages/build_spine_page.py` 是动作实验（网格变形、Spine 骨骼），结论是写实 AI 图做大幅动作效果差，**当前需求不再使用**，仅作参考。

## 之前试验得到的经验

- OpenAI 安全过滤会拒绝内衣打底的素模、比基尼；连体泳衣可以。打底衣用贴身背心 + 骑行短裤。
- 灰色打底衣和白色/浅蓝衣服太接近，导致抠图残留或误删。**新素模改用亮绿色打底衣**，抠图后：边缘去绿（despill），并统计绿色残留像素作为硬性检查。
- 卡其、米色等接近肤色的衣服会被颜色模型误判为皮肤：分割模型判断为衣服的地方一律不当皮肤。
- 敞开外套叠穿时边缘有残留，是上一版最难的问题，绿色打底衣主要就是为它准备的。
- 需要检查：复原误差、覆盖（漏底）、叠穿、三种肤色、绿色残留、两个姿势的一致性、脸是否被改。

## 环境

- Python 依赖：`opencv-python-headless numpy pillow mediapipe requests`（MediaPipe 需要系统库 `libegl1 libgles2`）。
- MediaPipe 模型：`pose_landmarker_heavy.task`、`selfie_multiclass_256x256.tflite`（从 storage.googleapis.com/mediapipe-models 下载到 `models/`）。
- 脚本假设在同一个工作目录下运行（`base.png`、`d_<衣服>.png` 等文件放在当前目录）。
