# 飞机为什么能飞上天？（儿童科普动画）

`how-planes-fly.mp4`：约 6 分钟，中文配音和字幕，适合小朋友观看。

| 场景 | 内容 |
| --- | --- |
| 开场 | 大客机有几十头大象那么重，为什么能飞？ |
| 四个力在拔河 | 升力、重力、推力、阻力 |
| 推力从哪儿来 | 松手的气球 → 喷气发动机（吸气、压紧、加热、往后喷） |
| 机翼的秘密 | 机翼切面、迎角；绕机翼气流动画（按真实的势流计算）：上面快、气压小，下面慢、气压大，把空气往下推 |
| 动手试一试 | 吹纸条、举着纸板跑 |
| 起飞要跑得快 | 速度越快升力越大、跑道加速、放风筝 |
| 怎么转弯 | 升降舵、方向舵、副翼 |
| 举一反三 | 鸟的翅膀、直升机和竹蜻蜓、赛车尾翼、帆船 |
| 总结 + 思考题 | 为什么飞机喜欢迎着风起飞？ |

思考题答案（给家长）：升力取决于机翼和空气之间的相对速度。迎着风起飞时，飞机还没跑多快，
吹过机翼的风就已经很快了，所以能更早获得足够的升力，跑道也能更短。风筝迎着风更容易飞起来，也是同一个道理。

## 重新生成

依赖：Python 3、`pycairo`、`numpy`、`edge-tts`、`ffmpeg`。

```sh
python3 tts.py      # 逐句生成配音（edge-tts，晓晓），写入 build/
python3 render.py   # 渲染各场景动画、合成配音 → build/how-planes-fly.mp4
python3 render.py --still airflow 20 out.png   # 预览某个场景某一秒的画面
```

旁白文字都在 `script.py` 里，改完重新运行上面两步即可。
